# Akiba

Akiba is a Collaborative Financial Platform being developed by Globe Software, a division of Globe Technologies Ltd.

## Engineering status

This repository is being initialized from the CEO-approved Akiba Product Blueprint v1 implementation packets. See `docs/` for the engineering plan, domain dictionary, requirements register, and architecture decisions.

## Principles

- Financial Universes are the primary collaborative context.
- Financial records are auditable; posted ledger entries are append-only.
- Withdrawal approval is distinct from payment execution.
- Payment provider events must be authenticated and idempotent.
- No real-money movement is enabled in the initial development milestones.
